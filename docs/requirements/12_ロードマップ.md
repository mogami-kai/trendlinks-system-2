# 12. ロードマップ・品質ゲート

## 12.1 開発フェーズ

### Phase 0: 基盤セットアップ
- Next.js 14（App Router）+ TypeScript + Tailwind（emerald）雛形。
- Supabase プロジェクト（dev/prod）、Auth・Storage・migrations。
- Vercel 連携・環境変数・CI（GitHub Actions）。

### Phase 1: MVP（資料の「Phase 1 MVP」相当）
- 認証・マルチテナント・RBAC（`07`）。
- FR-1 現場管理 / FR-2 作業指示 / FR-4 報告+写真。
- FR-3 LINE 配信 / FR-5 GPS 到着 / FR-6 PDF 生成。
- Stripe 3 プラン・機能ゲート（`08`）。
- 法務 4 ドキュメント（`11`）。

### Phase 2: 拡張（Out of Scope だった項目）
- 顧客ポータル（PDF 閲覧）、勤怠/シフト高度化、請求書発行。
- PWA / オフライン下書き、地図・ルート最適化。
- 分析ダッシュボード、多言語対応。

## 12.2 品質ゲート（資料の「エラー・警告のない品質ゲート」を踏襲）

| ゲート | 基準 |
|---|---|
| Lint | ESLint エラー/警告 0 |
| 型 | `tsc --noEmit` エラー 0 |
| テスト | 単体/結合テスト通過（主要動線をカバー） |
| ビルド | `next build` 成功 |
| E2E（推奨） | 認証→現場→指示→到着→報告→PDF の主要シナリオ |

- CI（GitHub Actions）で上記を PR ごとに自動実行（`10`）。

## 12.3 受入（リリース判定）
- `00`〜`11` の各受入基準を満たす。
- 6 大機能 + 認証 + 決済 + 法務が動作し、マルチテナント分離（RLS）が検証済み。
- 本番キー切替で即時収益化可能な状態（`08`）。

## 12.4 残課題（実機調査で確定すべき項目）
- データモデルの実スキーマ突合（`04`）。
- 画面/ルートの実構成突合（`05`）。
- 認証 17 機能の正確な内訳（`07`）。
- Free/Starter における GPS・PDF の可否（`08`）。
