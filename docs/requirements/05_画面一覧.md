# 05. 画面一覧・UI 要件

> 画面の細部は **«推定»**。実機調査後に確定する。

## 5.1 デザイン方針
- フレームワーク: Next.js 14 App Router + Tailwind CSS。
- **ブランドカラー: emerald（緑系）**。CTA・アクティブ状態に使用。
- スマホ完結 UX を最優先。モバイルはボトムタブ/大きな CTA、PC はサイドナビ。
- アイコン主体・最小ステップ・大きいタップ領域。

## 5.3 主要画面の要件

### ダッシュボード
- 当日の作業指示、到着/報告の進捗、未読通知、プラン利用状況（上限バー）。

### 現場一覧/詳細
- 一覧: 検索、ステータス・担当でフィルタ、地図ピン（任意）。
- 詳細: 契約内容、担当、関連作業指示・報告履歴、緯度経度の確認/修正。

### 作業指示一覧
- フィルタバー: 現場・スタッフ・日程範囲（カレンダー）・ステータス。
- 作成時に「LINE 配信する」トグル。

### GPS 到着確認（スマホ）
- 大きな「到着」ボタン → 位置取得 → 距離表示（200m 判定）→ 結果表示。
- 失敗/圏外時は手動申請フォーム。

### 現場報告（スマホ）
- 写真追加（カメラ/ギャラリー、最大 5・残枚数表示・並び替え）、コメント、提出。

### PDF プレビュー
- レイアウトプレビュー、生成、ダウンロード、顧客メール送付（宛先選択）。

### 課金
- 3 プラン比較、現在プラン、アップグレード/ダウングレード、請求履歴、
  上限到達時のアップグレード導線。

## 5.4 共通 UI
- ナビ: モバイル＝ボトムタブ（ホーム/現場/指示/報告/設定）、PC＝サイドバー。
- トースト通知、ローディング/スケルトン、空状態、エラーバウンダリ。
- 確認ダイアログ（削除等の破壊的操作）。
