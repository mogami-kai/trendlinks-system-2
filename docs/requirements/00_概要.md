# 00. 概要（プロジェクト概要・スコープ）

## 0.1 ドキュメントの位置づけ

本ドキュメント群は、清掃業・ビルメンテナンス・ハウスクリーニング業界向けの
クラウド型サブスクリプション SaaS「**Trendlinks（仮称：現場管理 SaaS）**」と
同等のシステムを**新規に構築するための要件定義書一式**である。

- 対象読者: プロダクトオーナー、開発者、デザイナー、運用担当
- 成果物の性質: 実装前の要件定義（What を定義し、How の方針を示す）
- 記述言語: 日本語

### 参照元・前提

| 項目 | 内容 |
|---|---|
| 元システム | `trendlinks-app.vercel.app`（Supabase 認証 + Vercel ホスティング） |
| 要件のソース | 譲渡資料（商品説明・特徴・顧客像・強み・譲渡情報） |
| 技術スタック方針 | **Supabase + Vercel 構成**（実デプロイに準拠） |

> **注記（実機調査について）**
> 本要件定義の作成時点では、開発環境のネットワーク・エグレス・ポリシーにより
> `*.supabase.co` および `*.vercel.app` への到達が遮断されており（HTTP 403）、
> 稼働中システムへのログインによる実機調査は実施できなかった。
> よって**データモデル・画面・API は譲渡資料に基づく推定**であり、
> 到達可能な環境が用意され次第、実機調査（`05_画面一覧.md` / `04_データモデル.md`）の
> 確定作業を行うこと。推定箇所には «推定» と明示する。

## 0.2 背景・目的

### 背景
- 全国の清掃業者は約 **5 万社**。うち紙・Excel・LINE のみで運用する
  デジタル化未満の事業者が約 **3 万社**（SAM）と推計される。
- 既存競合は月額 ¥5,000 前後で、1〜20 名規模の小・中規模事業者には高価。
- 「現場管理 + スタッフシフト + 現場報告 + 顧客向け報告書 PDF 自動生成」を
  ワンパッケージで安価に提供するサービスは少ない。

### 目的
- スマートフォン 1 台で完結する清掃現場管理 SaaS を提供する。
- 月額 **¥1,980 から**の低価格帯で、デジタル化未満の事業者の参入障壁を下げる。
- **顧客報告書 PDF 自動生成**という差別化機能でリピート契約率を高める。

## 0.3 対象業界・ターゲット顧客

主対象は **1〜20 名規模**の以下の事業者：

- 小・中規模の清掃会社（ビル清掃・店舗清掃・住宅清掃）
- ハウスクリーニング業者（エアコン・水回り・引越し清掃）
- ビルメンテナンス会社（定期保守 + 清掃の複合業態）
- 特殊清掃・遺品整理業者
- 不動産管理会社の清掃部門

利用デバイスは**スマートフォン完結**を主とし、タブレット・PC からもアクセス可能な
マルチデバイス（レスポンシブ）対応とする。

## 0.4 ビジネスモデル（概要）

サブスクリプション課金（Stripe）による 3 プラン構成。詳細は `08_決済_プラン.md`。

| プラン | 月額 | 上限 | 主機能 |
|---|---|---|---|
| Free | ¥0 | 現場 3 件・スタッフ 5 名 | 標準機能（リード獲得用） |
| Starter | ¥1,980 | 現場 20 件・スタッフ 20 名 | 標準機能 |
| Pro | ¥4,980 | 無制限 | GPS 到着確認・顧客報告書 PDF 自動生成 を含む |

## 0.5 システムの主要機能（サマリ）

| ID | 機能 | 概要 | 詳細 |
|---|---|---|---|
| F1 | 現場（Site）管理 | 現場の CRUD（現場名・住所・担当・契約内容） | `02_機能要件.md` FR-1 |
| F2 | 作業指示書（WorkOrder）管理 | 現場別・スタッフ別・日程範囲フィルタ対応の CRUD | FR-2 |
| F3 | 作業指示配信 | LINE Messaging API でスタッフ一斉配信 | FR-3 |

| F5 | GPS 到着確認 | 位置情報 API + haversine 200m 判定で到着自動記録 | FR-5 |
| F6 | 顧客報告書 PDF | 写真・担当・コメントを 1 クリックで PDF 化 | FR-6 |
| F7 | 認証・認可 | 認証 17 機能・マルチテナント・RBAC | `07_認証認可.md` |
| F8 | サブスク決済 | Stripe 3 プラン・機能ゲート | `08_決済_プラン.md` |

## 0.6 スコープ

### 対象（In Scope）
- 上記 F1〜F8 の全機能
- マルチテナント（1 社経営〜複数拠点展開）
- 法務 4 ドキュメント（プライバシーポリシー / 利用規約 / 特定商取引法表記 / FAQ）
- レスポンシブ Web アプリ（スマホ / タブレット / PC）
- 本番・開発の 2 環境構成と CI/CD

### 対象外（Out of Scope）— 初期版（MVP）
- ネイティブモバイルアプリ（iOS/Android。Web レスポンシブで代替）
- スタッフの勤怠給与計算・請求書発行（将来拡張：`12_ロードマップ.md`）
- 在庫・備品・車両管理
- 多言語対応（日本語のみ。将来拡張）
- 大規模 BI / 高度な分析ダッシュボード

## 0.8 用語集

| 用語 | 説明 |
|---|---|
| テナント（Tenant） | サービスを契約する清掃事業者（会社）。データ分離の単位 |
| 現場（Site） | 清掃対象のビル・店舗・住宅などの作業場所 |
| 作業指示書（WorkOrder） | 特定の現場・スタッフ・日程に対する作業の指示 |
| 現場報告（Report） | スタッフが作業完了後に提出する報告（写真・コメント） |
| GPS 到着確認 | 現場座標とスタッフ端末の座標を比較し到着を自動記録する機能 |
| haversine | 2 地点の緯度経度から大円距離を求める計算式（到着判定に使用） |
| 顧客（Customer） | テナントの取引先。PDF 報告書の送付先 |
| RLS | Row Level Security（PostgreSQL の行レベルセキュリティ。テナント分離に使用） |
| MRR / ARR | 月次経常収益 / 年次経常収益 |
