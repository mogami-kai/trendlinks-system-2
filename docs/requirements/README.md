# 要件定義書一式 — 清掃業向け現場管理 SaaS（Trendlinks クローン）

清掃業・ビルメンテナンス・ハウスクリーニング業界向けの現場管理 SaaS
（現場管理 + 作業指示 + 現場報告 + GPS 到着確認 + 顧客報告書 PDF 自動生成）を
**新規構築するための要件定義書**一式。技術構成は実デプロイに準拠し
**Supabase + Vercel** を採用する。

## 重要な前提

- **技術スタックの食い違い**: 譲渡資料は FastAPI/Python + k3s + Cloudflare R2 を
  記載するが、実デプロイは Supabase + Vercel。本要件は後者を採用し、各章で
  マッピングを注記する（[01](./01_システムアーキテクチャ.md) 参照）。
- **実機調査は未実施**: 開発環境のネットワーク制約により稼働システムへ到達不可
  （HTTP 403）。データモデル・画面・API は資料に基づく **«推定»** であり、
  到達可能環境での実機調査後に確定する（[12](./12_ロードマップ.md) 残課題）。
